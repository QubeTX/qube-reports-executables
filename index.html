Your offline toolkit

TR-300, ND-300 with SpeedQX, and SD-300 with its desktop app. Open this page from the extracted folder; it needs no internet, JavaScript, or external fonts.

Choose your installer

Choose your tool, then the destination computer’s operating system and processor. On Windows, choose Standard (Global) for all users or Corporate for your account, then MSI or EXE. For upgrades, use the same edition and format as your existing installation.

On Mac, the universal PKG supports both Intel and Apple Silicon. The TR-300 and ND-300 compatibility DMGs contain the same PKGs. On Linux, match the processor and C library. Portable CLI and Desktop downloads have separate folders.

Extract the entire ZIP. Open PowerShell on Windows or a terminal on macOS or Linux in the folder containing your chosen file. Paste the single line from its README and press Enter. SD-300 native installers include its desktop app.

SD-300 Desktop on Windows uses the Microsoft Visual C++ x64 runtime. If your computer needs it, the Windows command guides open the included offline runtime installer. IT can install this prerequisite before a Corporate deployment. Windows N also requires the Media Feature Pack for your Windows release.

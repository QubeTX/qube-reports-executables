Your offline toolkit

TR-300, ND-300 with SpeedQX, and SD-300 with its desktop app. Open this page from the extracted folder; it needs no internet, JavaScript, or external fonts.

Start here

  1. Extract the entire bundle first. Keep its folders together.
  2. Choose a tool below and the files for your operating system.
  3. Windows: use one MSI or EXE edition. Global needs administrator access; Corporate installs for the current user. macOS: use the universal PKG. Linux: extract the matching archive.
  4. Open a fresh terminal after installation. Run tr300, nd300, speedqx, or sd300. Native SD-300 installers also install the desktop app; open it from the application menu or run sd300 gui.

SD-300 portable desktop app

The native Windows MSI/EXE and macOS PKG include both terminal and desktop tools. Separate portable GUI archives are also provided for all supported targets.

  • Windows: extract sd300-gui-windows-x86_64.zip into its own folder. Keep the DLL, assets, licenses and manifest beside sd300-gui.exe, then open that executable.
  • macOS: extract sd300-gui-macos-universal.zip and open the app bundle.
  • Linux: extract the matching sd300-gui-linux-…tar.xz archive and run ./sd300/bin/sd300-gui. Keep the whole sd300/ directory. A working graphical desktop and compatible system libc are required.

The CLI archive is separate from these portable GUI files. Extract it separately for terminal use. Portable extraction does not create a managed-install receipt, PATH entry, or application-menu shortcut.

Keep companion commands together

TR-300 archives contain tr300 and report. ND-300 archives contain nd300 and speedqx. Extract both companions together. SD-300 CLI archives retain their historical tr300-tui- filename prefix; the command inside is sd300.

Upgrades

For an offline upgrade, run the included official installer matching the existing format and edition. This is particularly important for SD-300 3.x to 4.x. Do not mix MSI and EXE registrations or replace just one file in a managed SD-300 installation. Use the current product guide for ownership conflicts. Self-update commands need internet access.

Verify before installing

Compare a downloaded file's SHA-256 hash with its adjacent .sha256 file. The root checksum list covers every file in this bundle except itself. Verification needs no network:

Linux:   sha256sum -c SHA256SUMS.txt
macOS:   shasum -a 256 -c SHA256SUMS.txt
Windows: .\scripts\Verify-Bundle.ps1

If your operating system or organization blocks an installer, keep that diagnostic and verify the source and checksum. These files do not bypass endpoint policy. Windows packages target x64; ARM64 Windows is not qualified by this bundle.

Release binaries are unchanged from their official tagged releases. Product manuals, release notes, licenses, and supporting Markdown documents are included under each product's docs/ folder. They can be opened in a text editor; external links and linked media may require internet. The pinned versions and source hashes are recorded in bundle-manifest.json.

# Changelog

All notable changes to the `qube-reports-executables` distribution repository are documented in this file.

---

## [3.0.0] - 2026-10-11

### Changed

- Refresh the pinned offline snapshot to TR-300 v4.4.0, ND-300 v4.0.1, and SD-300 v4.1.0. WB-300 and Shaughv OS are excluded.
- Publish a curated `qubetx-offline-bundle.zip` release asset rather than relying on a repository source ZIP as the primary download.
- Rewrite installation and upgrade guidance to distinguish native installation, portable extraction, offline setup, network-dependent features, and SD-300 3.x-to-4.x upgrades.

### Added

- SD-300 GUI archives for Windows, macOS, Linux x64 GNU, Linux ARM64 GNU, and Linux x64 musl; native installers already contain CLI and GUI together.
- macOS portable CLI archives for all three products; keep companion `report` and `speedqx` binaries in their original archives.
- A fully local HTML start page, pinned upstream documentation/licenses, release provenance manifest, complete checksums, and an offline PowerShell verifier.
- Reusable build/packaging scripts that fail on missing assets, moved tags, digest mismatches, corrupt archives, or unexpected payload files.

### Verification

- Every payload is compared with its official sidecar and GitHub release digest; every archive is read for integrity before publication. Platform runtime qualification is reported separately in release notes.

---

## [2.0.0] - 2026-07-19

### Changed

- Refreshed TR300 to v4.2.2, ND300 to v3.7.3, and SD300 to v2.0.2 from their qualified public GitHub Releases.
- Replaced legacy per-architecture DMGs with each product's signed, notarized universal macOS PKG.
- Added current Global and Corporate MSI/EXE installer channels plus portable Windows ZIPs.
- Replaced versioned legacy artifact conventions with the stable public filenames used by each product's `releases/latest/download` channel.
- Rewrote the offline install guide around same-channel updates and deliberate fresh-install intent.
- Kept SD300 immediately after ND300 in the bundle, guide, and product inventory.

### Verification

- Every bundled artifact is checked against its public `.sha256` sidecar.
- Each product-level `sha256.sum` covers all bundled artifacts and sidecars.

## [1.1.0] — 2026-02-25

### Summary

Added a plain-English user install guide for non-technical users and removed the online-only installer scripts that don't serve the offline distribution use case.

### Added

- **`USER-INSTALL-GUIDE.md`** — Layman-friendly install guide with:
  - Step-by-step instructions for identifying your computer type (Mac/Windows/Linux, chip type)
  - Per-tool file lookup tables mapping plain-English computer descriptions to exact filenames
  - OS-specific installation walkthroughs written for non-developers
  - Troubleshooting section covering macOS Gatekeeper, Windows SmartScreen, and Linux permissions

### Removed

- **6 online-only installer scripts** — These scripts (generated by cargo-dist) download binaries from GitHub by default, making them useless for offline distribution:
  - `TR300-qube-machine-report/tr-300-installer.sh`
  - `TR300-qube-machine-report/windows/tr-300-installer.ps1`
  - `ND300-qube-network-diagnostics/nd-300-installer.sh`
  - `ND300-qube-network-diagnostics/windows/nd-300-installer.ps1`
  - `SD300-qube-system-diagnostics/sd-300-installer.sh`
  - `SD300-qube-system-diagnostics/windows/sd-300-installer.ps1`

### Changed

- **`README.md`** — Added link to User Install Guide, removed all references to installer scripts, updated file inventory (45 → 39 files, 15 → 13 per tool), updated directory tree
- **`DISCOVERIES.md`** — Updated Section 9 to note installer scripts were removed from the distribution repo

### File Inventory

**39 binary/installer files** + **5 documentation files** (was 45 + 4)

## [1.0.0] — 2026-02-25

### Summary

Initial population of the distribution repository with offline installers for all three Qube TX 300 Series CLI tools, covering macOS (Apple Silicon + Intel), Windows (x86_64), and Linux (x86_64 glibc/musl + ARM64 glibc).

### Added

#### Binaries & Installers (45 files total)

**TR300 — qube-machine-report v3.6.0**
- `macos/tr300-aarch64-apple-darwin.dmg` — Apple Silicon DMG, Developer ID signed
- `macos/tr300-x86_64-apple-darwin.dmg` — Intel Mac DMG, Developer ID signed
- `windows/tr-300-x86_64-pc-windows-msvc.msi` — Windows MSI installer
- `windows/tr-300-x86_64-pc-windows-msvc.zip` — Windows portable archive
- `windows/tr-300-installer.ps1` — PowerShell installer script
- `linux/tr-300-x86_64-unknown-linux-gnu.tar.xz` — Linux x86_64 (glibc)
- `linux/tr-300-x86_64-unknown-linux-musl.tar.xz` — Linux x86_64 (musl/Alpine)
- `linux/tr-300-aarch64-unknown-linux-gnu.tar.xz` — Linux ARM64
- `tr-300-installer.sh` — Shell installer script (macOS/Linux)
- `sha256.sum` — SHA256 checksums for all upstream release artifacts
- Per-artifact `.sha256` checksum files for Linux and Windows archives

**ND300 — qube-network-diagnostics v2.6.0**
- Same set of artifacts as TR300 with `nd-300`/`nd300` naming convention

**SD300 — qube-system-diagnostics v1.2.1**
- Same set of artifacts as TR300 with `sd-300`/`sd300` naming convention

#### macOS Code Signing

All 6 macOS binaries (2 per tool) were signed locally after downloading from GitHub Releases:
- **Signing identity:** Developer ID Application: ES Development LLC (M9D5379H93)
- **Certificate chain:** Developer ID Application → Developer ID Certification Authority → Apple Root CA
- **Hardened runtime:** Enabled (required for future notarization)
- **Timestamps:** Apple's secure timestamp server
- **Format:** Binaries extracted from CI-built `.tar.xz`, signed with `codesign`, packaged into `.dmg` via `hdiutil`

#### Documentation

- `README.md` — Comprehensive install instructions for all platforms with architecture guidance
- `CHANGELOG.md` — This file
- `DISCOVERIES.md` — Detailed process notes, findings, and lessons learned

#### Runbook Update

- Added "Quick Path — Download Pre-Built Releases" section to `qube-tx-build-runbook.md`
- Documents the discovery that cargo-dist CI already produces all needed artifacts
- Includes `gh release download` commands and local macOS signing instructions
- Clarifies that the full local build pipeline (Phases 1–5) is only needed for custom formats
